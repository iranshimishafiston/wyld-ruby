## 🚀 Getting Started
Follow these steps to download and run **wyld-ruby** on your computer.

### Step 2: Download the Software
On the Releases page, you will find different versions listed. Choose the most recent version by looking for the latest release note. Click on the corresponding download link, such as `wyld-ruby-vX.X.X.zip`, to start downloading the file.

### Step 3: Extract the Files
Once the download is complete, locate the downloaded `.zip` file on your computer. It is typically in your "Downloads" folder. Right-click the file and select "Extract All" to unzip the contents.

### Step 4: Install Required Software
Before running **wyld-ruby**, ensure you have the following software installed on your computer:
- **Node.js**: This is required to run Next.js applications. Download it from [nodejs.org](https://nodejs.org/).
- **npm**: This usually comes with Node.js and is used to manage JavaScript packages.

### Step 5: Open the Terminal or Command Prompt
To run the application, open your command line tool:
- On **Windows**, you can use Command Prompt or PowerShell.
- On **macOS**, open Terminal from the Applications folder.

### Step 6: Navigate to the Project Directory
Use the command line to navigate to the folder where you extracted the **wyld-ruby** files. You can do this with the following command:
```
cd path_to_your_extracted_folder
```
Replace `path_to_your_extracted_folder` with the actual path to that folder.

### Step 7: Install Dependencies
Run the following command in your terminal or command prompt to install the necessary dependencies:
```
npm install
```
This will allow the application to access required packages.

### Step 8: Run the Application
To start the gallery, execute the following command:
```
npm run dev
```
After running this command, you should see output indicating that the server is running.

### Step 9: Access the Gallery
Open your web browser and go to `http://localhost:3000`. Here, you will find the **wyld-ruby** gallery live and ready for exploration.
